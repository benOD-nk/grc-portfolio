# TrustCom Asset Inventory & Classification Scheme
*Simulated case study — all people, data, and events are fictional.*

## Situation
TrustCom had no single list of its assets, data was classified by habit instead of by rule, and a network scan found a device nobody could identify.

## What I did
- Built an asset inventory of 7 assets, each with a named owner, the data it holds, its classification, and its status
- Defined a 4-level classification scheme (Public / Internal / Confidential / Restricted) with handling rules per level, including that the label must travel with the file
- Recorded two findings the work itself surfaced: an unlabelled Confidential payroll file, and an unknown device quarantined on discovery
- Stated the DLP limit honestly: it cannot see a photo of a screen, so that gap is documented rather than claimed covered

## Deliverable
Asset inventory + classification scheme — 7 assets, 4 classes, 2 findings with fixes. Artifact is in this folder.

## Skills demonstrated
Asset management · data classification & labelling · control-limit analysis · evidence-grade documentation
