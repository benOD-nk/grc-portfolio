# Benaiah Odamtten — Cybersecurity GRC Portfolio

Cybersecurity GRC Analyst based in Winnipeg, Canada. I work in governance, risk and compliance: ISO/IEC 27001 gap assessments, control design and testing, risk registers, and audit support.

This repository holds hands-on projects that show the work, not just the words. Every project is a **simulated case study** built on **TrustCom**, a fictional 25-person SaaS company. No real client information appears anywhere in this repository.

## Projects

| # | Project | What it shows |
|---|---------|---------------|
| 01 | [TrustCom GRC Charter](01-trustcom-grc-charter/) | Setting up a GRC function: purpose, scope, roles, and how governance runs in a small company |
| 02 | [TrustCom Risk Register](02-trustcom-risk-register/) | Identifying and assessing risks on a 3×3 matrix, with treatments, owners, due dates and signed-off residual risk |
| 06 | [TrustCom Asset Inventory & Classification Scheme](06-trustcom-asset-inventory/) | An asset inventory where every asset has a named owner and handling rules, plus a 4-level data classification scheme, with the gaps the work surfaced recorded as findings |
| 07 | [User Access Review & Access Control Model Analysis](07-trustcom-access-control-review/) | A full user access review: access list reconciled against a role matrix, five findings (dormant leaver account, separation-of-duties conflict, link oversharing, a privileged account outside conditional access, vendor access beyond contracted hours), remediation tracked to retest |

## How each project is built
One folder per project. Inside each folder: a README that tells the story (scenario, method, findings) and the actual deliverable file beside it — a workbook, a register, a one-pager. Evidence comes from system exports and lists, not screenshots.
